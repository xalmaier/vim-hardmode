# Vim: Hardmode

![Vim](https://img.shields.io/badge/supports-Vim-green?logo=vim)
![License](https://img.shields.io/badge/license-MIT-green)

A minimalist hardmode plugin for Vim to break muscle memory and eliminate bad navigation habits because WTF, use hjkl!

## Features
- **Arrow Lockout:** Completely kills arrow keys across all primary modes.

## Installation

### Via vim-plug (.vimrc)
```vim
Plug 'xalmaier/vim-hardmode'
```
